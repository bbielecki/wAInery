# Runtime modules — Gate 2 proposal

All modules are *logical bounded-context ownership scopes in one local .NET process*. Each module has a reserved directory and documentation but **no code is authorized until Gate 2 is accepted and Gate 3 contracts/components are agreed**.

Core: `Vineyard`, `Winery`, `Decisions`.
Supporting: `Observations`, `Weather`, `Knowledge`.
Platform: `Connectivity`, `AIExecution`.

See `docs/20-domains/context-map.md` and `docs/20-domains/ownership-matrix.md`.
